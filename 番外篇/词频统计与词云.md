## 词频统计与词云

词频统计是文本处理中最经典的应用场景之一：把一篇文章中出现次数最多的词语找出来，就能大致了解这篇文章在讲什么。配合**词云**（wordcloud）技术，还可以把统计结果画成一张漂亮的图片。这一篇我们就以《哈姆雷特》和《三国演义》为例，把英文词频统计、中文分词和词云绘制一次性讲清楚。

#### 1. 英文词频统计：以《哈姆雷特》为例

英文文本的单词之间本来就有空格分隔，所以处理起来比较简单，基本套路是三步：**文本预处理** → **用字典统计** → **按词频排序**。

##### 1.1 文本预处理

英文文本中除了单词，还会有标点符号（如`,`、`.`、`'`）和大小写混杂的情况。预处理要做的事情是：

- 把**大写字母统一转成小写**，否则`The`和`the`会被当成两个不同的单词；
- 把**特殊字符统一替换成空格**，这样后续按空格切分时就不会把标点带进单词里；
- 用`split()`方法**按空格切分出单词列表**。

```python
def getText():
    """读入英文文本并完成预处理"""
    txt = open("hamlet.txt", "r", encoding="utf-8").read()  # 读取整个文本文件
    txt = txt.lower()  # 所有的大写字母统一转成小写
    for ch in '!"#$%&()*+,-./:;<=>?@[\\]^_`{|}~':
        txt = txt.replace(ch, " ")  # 把特殊字符替换成空格，方便后续切分
    return txt  # 返回预处理后的文本
```

> **说明**：`str.replace(ch, " ")`会把字符串中所有的`ch`替换成一个空格，对特殊字符逐个处理一遍之后，文本里就只剩下小写字母、空格和换行符了。

##### 1.2 用字典统计词频

预处理完成后，用`split()`把文本切成单词列表，然后遍历这个列表，以**单词为键、出现次数为值**存入字典：

```python
hamletTxt = getText()  # 拿到预处理后的文本
words = hamletTxt.split()  # 按空格切分，得到单词列表
counts = {}  # 用字典来统计词频，键是单词，值是出现次数
for word in words:  # 遍历每一个单词
    counts[word] = counts.get(word, 0) + 1  # 累加计数，get的第二个参数表示单词第一次出现时从0开始
```

> **说明**：`counts.get(word, 0)`是一个很常用的写法，表示"如果`word`在字典中就取出它的值，否则返回0"，这样就不需要先判断单词是否已经在字典里了。

##### 1.3 按词频排序输出 TopN

字典本身是无序的，想找出出现次数最多的前N个单词，需要先把字典的键值对转换成列表，再按照**值（词频）从大到小**排序：

```python
items = list(counts.items())  # 把字典的键值对转换成列表，每个元素是(单词, 次数)元组
items.sort(key=lambda x: x[1], reverse=True)  # 按词频从大到小排序，reverse=True表示降序
for i in range(10):  # 输出词频最高的前10个单词
    word, count = items[i]  # 把元组拆包成单词和次数
    print("{0:<10}{1:>5}".format(word, count))  # 左对齐输出单词，右对齐输出次数
```

《哈姆雷特》全文统计后的输出大致如下（前10个高频词）：

```text
输出：
the        1138
and         966
to          741
of          655
i           569
you         542
a           530
my          514
hamlet      458
in          437
```

> **说明**：这里用到了`sort`方法的`key`参数，`lambda x: x[1]`表示按照元组中的第2个元素（也就是词频）来排序，这在《Python容器类型使用小技巧》中也有提到。如果不想用`lambda`，也可以写`key=operator.itemgetter(1)`。

下面把上面的代码整理成完整的程序：

```python
def getText():
    """读入英文文本并完成预处理"""
    txt = open("hamlet.txt", "r", encoding="utf-8").read()  # 读取整个文本文件
    txt = txt.lower()  # 所有的大写字母统一转成小写
    for ch in '!"#$%&()*+,-./:;<=>?@[\\]^_`{|}~':
        txt = txt.replace(ch, " ")  # 把特殊字符替换成空格
    return txt  # 返回预处理后的文本

hamletTxt = getText()  # 拿到预处理后的文本
words = hamletTxt.split()  # 按空格切分，得到单词列表
counts = {}  # 用字典统计词频
for word in words:  # 遍历每一个单词
    counts[word] = counts.get(word, 0) + 1  # 累加计数

items = list(counts.items())  # 键值对转换成列表
items.sort(key=lambda x: x[1], reverse=True)  # 按词频降序排序
for i in range(10):  # 输出前10个高频词
    word, count = items[i]  # 拆包得到单词和次数
    print("{0:<10}{1:>5}".format(word, count))  # 格式化输出
```

#### 2. jieba库和中文分词

中文和英文不一样，词与词之间**没有空格**，所以中文分词需要专门的工具。**jieba**是一个优秀的中文分词第三方库，安装方式如下：

```text
pip install jieba
```

> **说明**：jieba库的原理是先基于前缀词典扫描出句子中所有可能成词的情况，再生成一个有向无环图（DAG），最后用动态规划找出最大概率的切分路径，对于词典中没有登录的词，还会基于HMM模型进行新词发现。

##### 2.1 三种分词模式

jieba库支持三种常用的分词模式：

| 模式 | 函数 | 特点 |
| --- | --- | --- |
| 精确模式 | `jieba.lcut(s)` | 试图把句子最精确地切开，适合文本分析，没有冗余单词 |
| 全模式 | `jieba.lcut(s, cut_all=True)` | 把句子中所有可以成词的词语都扫描出来，速度快但有冗余 |
| 搜索引擎模式 | `jieba.lcut_for_search(s)` | 在精确模式的基础上，对长词再次切分，适合用于搜索引擎分词 |

下面用同一个字符串体验一下三种模式的区别：

```python
import jieba  # 导入jieba分词库

s = "中华人民共和国是1949年成立的"  # 待分词的字符串

print(jieba.lcut(s))  # 精确模式：最精确地切分，没有冗余
print(jieba.lcut(s, cut_all=True))  # 全模式：扫描出所有可能的词语，有冗余
print(jieba.lcut_for_search(s))  # 搜索引擎模式：精确模式基础上再切分长词
```

运行上面的代码，输出如下：

```text
输出：
Building prefix dict from the default dictionary ...
Loading model cost 0.344 seconds.
Prefix dict has been built successfully.
['中华人民共和国', '是', '1949', '年', '成立', '的']
['中华', '中华人民', '中华人民共和国', '华人', '人民', '人民共和国', '共和', '共和国', '国是', '1949', '年', '成立', '的']
['中华', '华人', '人民', '共和', '共和国', '中华人民共和国', '是', '1949', '年', '成立', '的']
```

> **说明**：`jieba.lcut`返回的是一个**列表**类型，这也是函数名中`l`（list）的由来。jieba第一次运行时会构建前缀词典，所以前面会打印一些构建词典的日志信息，属于正常现象。从输出可以明显看出：精确模式结果最"干净"，全模式词最多但有重叠冗余（比如"中华人民共和国"被整个输出，它的各个组成部分"中华"、"共和国"等也各自出现了），搜索引擎模式介于两者之间。

##### 2.2 向词典中添加自定义词汇

jieba的词典不可能涵盖所有领域的新词，如果某些专有名词（比如人名、产品名）被切开了，可以手动添加：

```python
import jieba  # 导入jieba分词库

s = "洛天依是一位虚拟歌手"  # 待分词的字符串，"洛天依"是人名，默认词典中没有收录
print(jieba.lcut(s))  # 默认分词，"洛天依"被切开了

jieba.add_word("洛天依")  # 向词典中添加"洛天依"这个自定义词汇
print(jieba.lcut(s))  # 再次分词，"洛天依"就不再被切开了
```

运行结果：

```text
输出：
['洛天', '依是', '一位', '虚拟', '歌手']
['洛天依', '是', '一位', '虚拟', '歌手']
```

如果要添加的词汇比较多，可以把它们写进一个文本文件（每行一个词），然后用`load_userdict`一次性加载：

```python
import jieba  # 导入jieba分词库

jieba.load_userdict("userdict.txt")  # 从文件加载用户自定义词典，文件中每行一个词
```

> **提示**：用户词典文件是普通的文本文件，编码建议使用UTF-8，每一行写一个词即可。

#### 3. 中文词频统计实例：《三国演义》人物出场统计

有了jieba，中文词频统计的套路就和英文差不多了，整体思路可以概括为四步：**分词 → 排除词库 → 计数 → 排序**。

1. **分词**：读入《三国演义》全文，用`jieba.lcut`切分成词语列表；
2. **排除词库**：像"曰"、"之"、"其"这样的虚词出现次数很多但没有分析价值，需要准备一个排除词库把它们过滤掉；
3. **计数**：遍历词语列表，用字典累加每个人名出现的次数；
4. **排序**：把字典转换成列表，按词频降序排序，输出前N个人物。

核心代码如下：

```python
import jieba  # 导入jieba分词库

excludes = {"将军", "却说", "荆州", "二人", "不可", "不能", "如此", "商议"}  # 排除词库，过滤无分析价值的词
txt = open("三国演义.txt", "r", encoding="utf-8").read()  # 读取《三国演义》全文
words = jieba.lcut(txt)  # 使用精确模式对全文进行分词
counts = {}  # 用字典统计词频

for word in words:  # 遍历每一个词语
    if len(word) == 1:  # 长度为1的单字通常不是有意义的人物名
        continue  # 跳过单字
    elif word in excludes:  # 如果词语在排除词库中
        continue  # 也跳过
    else:
        counts[word] = counts.get(word, 0) + 1  # 累加计数

items = list(counts.items())  # 键值对转换成列表
items.sort(key=lambda x: x[1], reverse=True)  # 按词频降序排序
for i in range(10):  # 输出出场次数最多的前10个人物
    word, count = items[i]  # 拆包得到人物名和出场次数
    print("{0:<10}{1:>5}".format(word, count))  # 格式化输出
```

《三国演义》全文统计后的输出大致如下：

```text
输出：
曹操         1443
孔明         1383
刘备         1252
关羽          784
张飞          358
吕布          300
孙权          264
赵云          255
司马懿         221
周瑜          217
```

> **说明**：实际操作中排除词库是逐步补充完善的——先跑一遍统计，发现结果中混进了没有分析价值的词语，就把它们加进`excludes`再跑一遍。另外，同一个人在书中可能有多种称呼（如"孔明"和"诸葛亮"、"玄德"和"刘备"），严格统计时还需要把这类称呼合并，感兴趣的读者可以自己尝试。

#### 4. wordcloud词云

词云是用词语组成的可视化图片，出现频率越高的词在图片中显示得越大。**wordcloud**库以wordcloud对象为基础，帮助我们方便地生成词云图。安装方式如下：

```text
pip install wordcloud
```

> **说明**：wordcloud库依赖pillow（PIL）和numpy，`pip install wordcloud`时pip会自动处理这些依赖。绘制中文词云时通常还会配合matplotlib来显示图片。

##### 4.1 典型使用流程

使用wordcloud生成词云只需要三步：**创建对象 → generate → to_file**。

```python
from wordcloud import WordCloud  # 导入wordcloud库中的WordCloud类

w = WordCloud()  # 第一步：创建WordCloud对象，可通过参数定制词云的外观
w.generate("Life is short, you need Python. Python is powerful.")  # 第二步：向对象中加载文本
w.to_file("wordcloud.png")  # 第三步：将词云输出为图片文件
```

运行后会在当前目录生成`wordcloud.png`图片文件，图片中的"Python"、"is"、"Life"等词会根据出现频率以不同的大小显示。

##### 4.2 常用参数

`WordCloud()`创建对象时可以传入很多参数来定制词云，常用的参数如下：

| 参数 | 说明 |
| --- | --- |
| `width` | 词云图片的宽度，默认为400像素 |
| `height` | 词云图片的高度，默认为200像素 |
| `background_color` | 图片的背景颜色，默认为黑色，常用"white"（白色） |
| `font_path` | 字体文件的路径，绘制**中文词云时必须指定**，否则中文会显示为乱码方框 |
| `mask` | 词云形状，传入一张图片对象，词云会按照图片的轮廓排布（默认为矩形） |
| `stopwords` | 要排除的词语集合，这些词不会出现在词云中 |
| `max_words` | 词云显示的最大词语数量，默认为200 |
| `scale` | 图片放大倍数，数值越大生成的图片越清晰，默认为1 |

下面是一个使用部分参数的例子：

```python
from wordcloud import WordCloud  # 导入WordCloud类

w = WordCloud(width=600,  # 图片宽度600像素
              height=400,  # 图片高度400像素
              background_color="white",  # 背景色设置为白色
              max_words=50,  # 最多显示50个词
              scale=2)  # 放大2倍，图片更清晰
```

> **说明**：`stopwords`参数接收一个集合，例如`stopwords={"the", "and"}`，词云生成时会自动忽略这些词。如果想使用内置的英文停用词，保持默认即可。

##### 4.3 generate与generate_from_frequencies

除了直接加载文本，wordcloud还支持**直接根据词频字典生成词云**，这两种方法配合不同的使用场景：

```python
from wordcloud import WordCloud  # 导入WordCloud类

w = WordCloud()  # 创建WordCloud对象
w.generate("Life is short, you need Python. Python is powerful.")  # generate：直接加载一段文本，库内部自动统计词频
w.generate_from_frequencies({"Python": 10, "Life": 5, "short": 3})  # generate_from_frequencies：直接传入词频字典
w.to_file("wordcloud.png")  # 输出词云图片
```

> **说明**：`generate(text)`方法内部会先用空格切分文本并统计词频，所以它**只适合英文**；如果我们已经用jieba分好词、统计好了词频字典，就应该使用`generate_from_frequencies(freq_dict)`，这正是中文词云最常用的方式。

##### 4.4 与jieba配合绘制中文词云

中文词云的完整流程是：**jieba分词 → 统计词频 → generate_from_frequencies生成词云**。这里有一个非常重要的注意点：**绘制中文词云必须指定`font_path`参数**，指定一个包含中文字符的字体文件，否则图片中的中文会显示为乱码方框。

Windows系统自带的中文字体存放在`C:\Windows\Fonts`目录下，常用的字体文件如`simhei.ttf`（黑体）、`simsun.ttc`（宋体）。

```python
import jieba  # 导入jieba分词库
from wordcloud import WordCloud  # 导入WordCloud类

txt = open("三国演义.txt", "r", encoding="utf-8").read()  # 读取中文文本
words = jieba.lcut(txt)  # 使用jieba精确模式分词
text = " ".join(words)  # 用空格把分好的词连接成一个字符串

w = WordCloud(font_path="C:\\Windows\\Fonts\\simhei.ttf",  # 指定黑体字体文件，中文词云必须指定否则乱码
              width=800,  # 图片宽度800像素
              height=600,  # 图片高度600像素
              background_color="white",  # 背景色为白色
              max_words=100,  # 最多显示100个词
              scale=2)  # 放大2倍让图片更清晰
w.generate(text)  # 加载文本并生成词云
w.to_file("三国演义词云.png")  # 将词云输出为图片文件
```

如果想配合matplotlib在窗口中直接查看词云，可以这样写：

```python
import jieba  # 导入jieba分词库
from wordcloud import WordCloud  # 导入WordCloud类
import matplotlib.pyplot as plt  # 导入matplotlib用于显示图片

txt = open("三国演义.txt", "r", encoding="utf-8").read()  # 读取中文文本
words = jieba.lcut(txt)  # jieba精确模式分词
text = " ".join(words)  # 用空格连接成分词后的字符串

w = WordCloud(font_path="C:\\Windows\\Fonts\\simhei.ttf",  # 中文字体，必须指定
              background_color="white",  # 背景色为白色
              width=800,  # 图片宽度
              height=600)  # 图片高度
w.generate(text)  # 生成词云

plt.imshow(w)  # 将词云对象作为图片绘制
plt.axis("off")  # 关闭坐标轴显示
plt.show()  # 显示图片窗口
```

> **说明**：matplotlib显示中文同样需要处理字体问题，但绘制词云时关键是`font_path`参数，只要它指定了中文字体，词云图片本身就不会乱码。`plt.imshow(w)`可以直接接收WordCloud对象，因为词云对象本质上就是一张图片的numpy数组表示。

#### 5. 用词频字典生成人物词云

最后，把前面学到的内容串起来：先用jieba统计《三国演义》的人物出场次数，再用`generate_from_frequencies`根据统计结果生成词云，这样词云中人物名的大小就对应出场次数的多少。

```python
import jieba  # 导入jieba分词库
from wordcloud import WordCloud  # 导入WordCloud类

excludes = {"将军", "却说", "荆州", "二人", "不可", "不能", "如此", "商议"}  # 排除词库
txt = open("三国演义.txt", "r", encoding="utf-8").read()  # 读取全文
words = jieba.lcut(txt)  # 分词
counts = {}  # 词频字典

for word in words:  # 遍历词语
    if len(word) == 1 or word in excludes:  # 跳过单字和排除词
        continue  # 直接进入下一次循环
    counts[word] = counts.get(word, 0) + 1  # 累加计数

w = WordCloud(font_path="C:\\Windows\\Fonts\\simhei.ttf",  # 指定中文字体
              background_color="white",  # 白色背景
              width=800,  # 图片宽度
              height=600,  # 图片高度
              max_words=50)  # 最多显示50个词
w.generate_from_frequencies(counts)  # 直接根据词频字典生成词云
w.to_file("三国演义人物词云.png")  # 输出词云图片
```

生成的词云图片中，"曹操"、"孔明"、"刘备"等出场次数多的人物名字会明显大于其他词语，一张图就能看出整部书的主角是谁。

###  总结

词频统计的核心套路是"预处理、分词、计数、排序"四步：英文文本靠大小写转换、特殊字符替换和`split`完成预处理，中文文本则要借助jieba的三种分词模式（精确模式、全模式、搜索引擎模式）；统计时用字典配合`get`方法累加计数，排序时把字典转换成列表再按值降序排列即可输出TopN。词云绘制使用wordcloud库，流程是"创建对象、generate、to_file"三步，中文词云务必指定`font_path`字体参数避免乱码，已经统计好词频字典时用`generate_from_frequencies`方法会更加方便。
