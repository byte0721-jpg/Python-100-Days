## 极简计算机基础

很多刚开始学 Python 的朋友其实是零基础入门，对计算机本身缺乏基本的了解，于是在学习过程中经常会遇到一些"卡壳"的地方：为什么硬盘是 512GB 但系统显示没那么多？IP 地址和网址是什么关系？程序到底是怎么跑起来的？这一篇番外篇就来为大家补充这些计算机常识，不求面面俱到，但求看完之后心里有数。

### 数值和数据

计算机的分工很明确：硬件负责"算"，数据就是被"算"的对象。要理解计算机，先要理解数据在计算机里是如何表示和度量的。

#### 数据单位：从 bit 到 TB

计算机内部使用**二进制**来表示数据，任何一个数据在计算机看来都是一串 0 和 1。二进制中的一个 0 或一个 1，我们称为一个**比特**（bit，位），它是数据的最小单位。

但是 bit 实在太小了，一个英文字母都需要 8 个 bit 才能表示，所以我们又规定 8 个 bit 为一个**字节**（Byte，B），字节是数据存储的基本单位。在字节的基础上，向上还有 KB、MB、GB、TB 等更大的单位，它们之间的换算关系是相邻单位之间 1024 倍（因为 $2^{10} = 1024$）：

| 单位 | 全称 | 换算关系 | 直观感受 |
| ---- | ---- | -------- | -------- |
| bit  | 位   | 最小单位 | 一个 0 或一个 1 |
| B    | 字节 | 1 B = 8 bit | 一个英文字符 |
| KB   | 千字节 | 1 KB = 1024 B | 一段短文、一张小图标 |
| MB   | 兆字节 | 1 MB = 1024 KB | 一首 MP3 歌曲约 3~10 MB |
| GB   | 吉字节 | 1 GB = 1024 MB | 一部电影约 1~3 GB |
| TB   | 太字节 | 1 TB = 1024 GB | 一块主流机械硬盘的容量 |

> **说明**：硬盘厂商为了计算方便，通常按 1 GB = 1000 MB 来标称容量，而操作系统按 1 GB = 1024 MB 来计算，所以大家买回来的 512GB 硬盘插到电脑上会发现"缩水"了，这不是质量问题，是两边的换算标准不一样。

下面的代码演示了如何用 Python 做单位换算，大家可以自己动手运行一下。

```python
# 硬盘标称容量（厂商按 1000 进制计算）
disk_size_gb = 512
# 厂商认为的总字节数
total_bytes = disk_size_gb * 1000 ** 3
# 操作系统按 1024 进制计算得到的 GB 数
real_gb = total_bytes / 1024 ** 3
print(f'标称容量：{disk_size_gb} GB')
print(f'系统显示：{real_gb:.1f} GB')  # 结果：476.8 GB
```

#### 常见的数据类型

计算机能处理的数据种类非常多，按表现形式通常可以分为以下几类：

| 类型 | 举例 | 在 Python 中的对应 |
| ---- | ---- | ------------------ |
| 数值 | 整数、小数（如 `1024`、`3.14`） | `int`、`float` |
| 文本 | 一篇文章、一条消息 | `str`（字符串） |
| 图像 | 照片、截图、图标 | 需借助 `Pillow` 等三方库处理 |
| 音频 | 歌曲、语音 | 需借助 `wave`、`pyaudio` 等处理 |
| 视频 | 电影、录屏 | 需借助 `opencv` 等三方库处理 |

> **说明**：无论数值、文本还是图像、音频、视频，在计算机内存和硬盘中最终都是二进制数据，区别只在于编码方式（如何用 0 和 1 解释这些数据）不同。图像是一个个像素点的颜色值，音频是对声音的采样值，视频则是连续的图像帧加上音频。这也是为什么我们用文本编辑器打开一张图片会看到一堆乱码——编辑器把二进制数据当文本去解释了。

数值和文本是最基础的两类数据，也是 Python 入门阶段接触最多的数据类型，大家在前面课程中学过的 `int`、`float`、`str` 正是这两类数据在 Python 中的体现。

### 计算机硬件

#### 冯·诺依曼结构

现代计算机大多采用**冯·诺依曼结构**（存储程序结构），它的核心思想可以概括为两句话：

1. **用二进制表示数据和指令**，数据和程序都以二进制形式存放在存储器中；
2. **计算机由五大部件组成**：运算器、控制器、存储器、输入设备、输出设备，程序预先存入存储器，计算机按照程序自动逐条执行指令。

这套思想从 1945 年提出至今，仍然是我们手里手机、笔记本、台式机的基本工作原理，可以说是所有计算机初学者都值得了解的一课。

#### 核心部件

冯·诺依曼结构中的五大部件，对应到我们身边的电脑上就是下面这些硬件：

| 部件 | 对应硬件 | 作用 |
| ---- | -------- | ---- |
| 运算器 + 控制器 | **CPU**（中央处理器） | 计算机的"大脑"，负责执行指令、完成运算和控制其他部件 |
| 存储器 | **内存**（RAM） | 临时存放正在运行的程序和数据，速度快但断电后数据丢失 |
| 存储器 | **外存**（硬盘、U 盘、光盘） | 长期保存数据，速度较慢但断电后数据不丢 |
| 输入设备 | 键盘、鼠标、麦克风、摄像头 | 把外界信息送入计算机 |
| 输出设备 | 显示器、音箱、打印机 | 把计算结果呈现给用户 |

> **提示**：内存和外存的区别是初学者最容易混淆的地方。可以打个比方：内存是你书桌上摊开的资料，拿取非常快，但桌面空间有限、下班（断电）就收走了；外存是你背后的书架，容量大、能长期保存，但翻找起来慢一些。所以"8GB 内存"和"512GB 硬盘"说的完全是两种东西。

#### 程序是如何执行的

理解了硬件，我们再来看**指令**和**程序**这两个概念。

- **指令**：就是让计算机完成一个基本操作的命令，例如"把两个数相加"、"从内存某个位置取出数据"。CPU 能识别的指令由它的设计决定，这被称为机器指令，是二进制形式的。
- **程序**：为了完成某个任务，把一系列指令按一定顺序组织起来，就构成了**程序**。我们写的 Python 源代码是给人看的文本形式的程序，运行时会被 Python 解释器翻译成计算机能执行的指令。

程序执行的大致流程是这样的：

1. 程序以文件形式保存在**外存**（硬盘）上；
2. 双击运行程序时，操作系统把程序从外存**装入内存**；
3. **CPU** 从内存中逐条取出指令、分析指令并执行指令，直到程序结束。

```python
# 一段简单的 Python 程序
a = 10          # 把 10 存入变量 a（数据放在内存中）
b = 20          # 把 20 存入变量 b
print(a + b)    # CPU 完成加法运算，结果 30 由输出设备呈现  # 结果：30
```

这段代码运行时，Python 解释器本身已经被装入内存，它负责把上面每一行代码翻译成机器指令交给 CPU 去执行。这就是为什么打开一个大软件需要几秒钟（从外存读入内存很花时间），而打开之后操作就流畅了（直接和内存打交道）。

### 计算机软件

硬件是躯体，软件是灵魂。计算机软件按照功能通常分为两大类：**系统软件**和**应用软件**。

#### 系统软件

**系统软件**是管理计算机硬件资源、为其他软件提供运行环境的软件，其中最核心的就是**操作系统**（Operating System，OS）。常见的操作系统有：

- **Windows**：个人电脑上市场占有率最高的操作系统；
- **macOS**：苹果电脑使用的操作系统；
- **Linux**：开源操作系统，服务器领域的绝对主力，我们课程中部署项目时会接触到它；
- **Android / iOS**：手机和平板上常见的移动操作系统。

操作系统负责进程管理、内存管理、文件管理、设备管理等底层工作。我们用鼠标双击一个图标能打开软件、用资源管理器能浏览文件，背后都是操作系统在提供服务。

> **说明**：系统软件中除了操作系统，还包括驱动程序、语言处理程序（如 Python 解释器、编译器）等。Python 解释器本质上也是一种系统软件，它负责把我们的 Python 代码翻译给计算机执行。

#### 应用软件

**应用软件**是为了解决某类具体问题而开发的软件，面向最终用户的日常需求。例如：

| 类别 | 举例 |
| ---- | ---- |
| 办公软件 | Word、Excel、WPS |
| 浏览器 | Chrome、Edge、Firefox |
| 开发工具 | VS Code、PyCharm |
| 聊天工具 | 微信、QQ |
| 音视频播放 | 网易云音乐、PotPlayer |

两者的关系可以概括为：应用软件运行在系统软件（操作系统）之上，操作系统运行在硬件之上。我们以后开发的 Python 程序，大多属于应用软件这个范畴。

### 计算机网络

#### 网络基础

今天的程序很少是孤立运行的，大多数都需要联网，所以几个网络基础概念必须弄清楚。

- **IP 地址**：网络中每台设备的"门牌号"，例如 `192.168.1.100`。有了 IP 地址，数据才能准确地从一台设备发送到另一台设备。目前广泛使用的是 IPv4 地址，由 4 个 0~255 的数字组成；新的 IPv6 地址则长得多。
- **域名**：IP 地址是一串数字，不好记，于是人们给网站起了好记的名字，例如 `www.python.org`，这就是**域名**。域名和 IP 地址是一一对应（或一对多）的关系。
- **DNS**（域名解析系统）：负责把域名翻译成 IP 地址的"电话簿"。你在浏览器输入 `www.python.org` 后，计算机会先去问 DNS 服务器"这个域名对应的 IP 是多少"，拿到 IP 地址之后再去访问真正的服务器。
- **带宽**：衡量网络传输数据快慢的指标，单位通常是 Mbps（兆比特每秒）。注意这里的单位是 bit 而不是 Byte，8 Mbps 的带宽理论上一秒钟最多传输 1 MB 的数据，所以 100 Mbps 宽带下载速度的"天花板"大约是 12.5 MB/s。

#### 客户端与服务器

网络程序的基本工作模式是**客户端**（Client）向**服务器**（Server）发起请求，服务器处理后把结果返回给客户端，这种模式称为 C/S 模式。

- **客户端**：发起请求的一方，例如你手机上的微信 App、电脑上的游戏客户端。
- **服务器**：提供服务的一方，通常是 24 小时不间断运行的高性能计算机，例如微信公司的服务器。

根据客户端的形态，常见的架构有两种：

| 架构 | 全称 | 客户端形态 | 举例 | 特点 |
| ---- | ---- | ---------- | ---- | ---- |
| C/S | Client/Server | 需要专门安装的客户端软件 | 微信、王者荣耀、网易云音乐桌面版 | 性能好、体验流畅，但需要安装和更新 |
| B/S | Browser/Server | 浏览器充当客户端 | 网页版邮箱、淘宝网站、各类 Web 管理系统 | 无需安装、升级方便，跨平台性好 |

> **提示**：B/S 架构本质上是特殊的 C/S 架构，只不过客户端被统一成了浏览器。我们后续课程中用 Django、Flask 框架开发的 Web 项目，就是典型的 B/S 架构应用；用户在浏览器输入网址（域名，经 DNS 解析成 IP 地址）向服务器发送请求，服务器把网页数据返回给浏览器展示。

### 常用 Python 编辑器

工欲善其事，必先利其器。写 Python 代码常用的编辑器和 IDE 有下面三种，各有侧重，初学者可以根据自己的情况选择。

#### IDLE

IDLE 是 Python 安装包**自带**的编辑器，安装完 Python 就能用，不需要额外安装。它界面简洁，支持交互式运行（就是我们熟悉的 REPL 环境）和简单的代码编辑，非常适合刚刚入门、连环境都还没配明白的朋友。缺点是功能比较简陋，没有代码补全的高级特性，项目稍大就不太够用了。

#### VS Code

VS Code 是微软推出的**免费开源**的轻量级代码编辑器，通过安装 Python 插件可以获得语法高亮、智能提示、调试、运行等完整的 Python 开发体验。它启动快、占用资源少、插件生态极其丰富，除了 Python 还能写前端、写文档，是近年来最流行的编辑器。对于希望一个工具通吃多种开发场景的学习者，VS Code 是很好的选择。

#### PyCharm

PyCharm 是 JetBrains 公司推出的**专业 Python IDE**（集成开发环境），分为免费的社区版（Community）和收费的专业版（Professional）。它对 Python 的支持最为完整：智能代码补全、重构、调试、测试、数据库工具、Web 框架支持一应俱全。缺点是比较吃内存、启动慢，专业版还需要付费（学生可以申请免费授权）。如果你确定要长期深入 Python 开发，尤其是做 Web 项目，PyCharm 是很值得投入的工具。

三者的对比如下表所示。

| 对比项 | IDLE | VS Code | PyCharm |
| ------ | ---- | ------- | ------- |
| 是否收费 | 免费（Python 自带） | 免费 | 社区版免费，专业版收费 |
| 软件类型 | 简单编辑器 | 通用代码编辑器 | 专业 Python IDE |
| 上手难度 | 最简单 | 较简单（需装插件） | 中等 |
| 功能丰富度 | 基础 | 丰富（靠插件扩展） | 最丰富 |
| 资源占用 | 极低 | 低 | 高 |
| 适合人群 | 刚入门的新手 | 多场景开发者 | 深度 Python 开发者 |

> **提示**：工具没有绝对的好坏，只有适不适合。我们的建议是：入门阶段用 IDLE 或 VS Code 就足够了，等开始做实际项目时再迁移到 PyCharm 也不迟。而且无论用什么工具，Python 代码本身是没有任何区别的，不要把时间浪费在纠结工具上。

###  总结

这一篇我们补齐了学习编程前应该了解的计算机常识：数据以二进制形式表示，用 bit、Byte、KB、MB、GB、TB 等单位度量；计算机硬件遵循冯·诺依曼结构，程序保存在外存、装入内存后由 CPU 逐条执行指令；软件分为系统软件和应用软件两层；网络世界中设备靠 IP 地址定位、域名经 DNS 解析、程序以 C/S 或 B/S 架构通过客户端与服务器协作；写 Python 代码可以选择 IDLE、VS Code 或 PyCharm，入门阶段工具够用就好，把精力放在代码本身才是正道。
